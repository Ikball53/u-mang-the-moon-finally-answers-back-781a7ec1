# The Moon Finally Answers Back

One line from the Moon, after 4.5 billion years of wishes: the tides stay free, the parking spot is $400 a month.

Run `python3 main.py` — it writes the Moon's reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
